# Vetra — cadastro

Primeira tela responsiva do MVP da plataforma Vetra. Feita em HTML, CSS e JavaScript puro para facilitar os primeiros ajustes.

Abra index.html no navegador. As fontes Manrope e Inter carregam do Google Fonts; sem internet, o sistema usa fontes locais.

O formulário demonstra seleção de perfil, validação de campos, aceite de termos e alternância da senha. O envio ainda é demonstrativo e não cria contas nem transmite dados.
